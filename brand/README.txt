DUCTECTIVE — LOGO PACK v1
=========================

PRIMARY MARK      Duct D — the letter D extruded into a duct, seen in perspective.
PALETTE           Ink #0C1826 · Steel900 #16283D · DuctBlue #1354BE
                  SignalBlue #2F93F2 · CyanRead #5CD0F5 · Steel400 #7D93AB
                  Steel200 #C6D3E0 · Mist #EFF4F9
TYPEFACE          Outfit (SIL Open Font License) — wordmark is already converted
                  to outlines, so no font install is needed to use these files.

svg/       Vector masters. Use these for print, signage, vehicle wrap and web.
png/       Raster exports. Marks/icons at 1024px, lockups at 4x.
favicon/   16 / 32 / 48 / 64 / 180 / 192 / 512 px, from the simplified mark.

WHICH FILE
  lockup-horizontal-light        default logo, light backgrounds
  lockup-horizontal-dark         default logo, dark backgrounds
  lockup-horizontal-notag-*      no tagline — use under ~160px wide
  lockup-stacked-*               square / narrow spaces
  lockup-horizontal-mono         one colour, ink (etch, embroidery, fax)
  lockup-horizontal-reversed     one colour, white
  wordmark-*                     type only
  mark-primary                   full mark, 32px and up
  mark-primary-small             simplified mark, 16px and up  <- favicons, app icons
  app-icon-dark/blue/light       squircle plates, 1024px
  mark-A..F                      the six concepts, in case you want to switch
  lockup-alt-*                   each alternate mark in the horizontal lockup

MINIMUM SIZES     full lockup 120px wide · full mark 32px · simplified mark 16px
CLEAR SPACE       equal to the width of the mark's vertical stem, all four sides
DO NOT            rotate, skew, shadow, or recolour the cyan accent.
